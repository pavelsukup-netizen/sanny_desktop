# Sanny assets

Aplikace používá uživatelskou složku:

`%APPDATA%\Sanny Desktop\assets\sanny`

Pro stavový panel vlož jeden z těchto souborů:

- `AI_ready.webm`
- `AI_ready.mp4`

Video se roztáhne na celou šířku panelu, výška zůstane automatická podle poměru stran. Když společný health check selže, video se zastaví na aktuálním snímku. Po obnovení služeb pokračuje ve smyčce.
